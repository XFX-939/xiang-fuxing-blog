# Cabinet Grotesk

The three webfont files in this directory are Cabinet Grotesk 400, 500, and 700 from Fontshare by Indian Type Foundry.

- Source: https://www.fontshare.com/fonts/cabinet-grotesk
- License: Fontshare Free Fonts License

They are self-hosted so the site does not depend on a third-party font request at runtime.
